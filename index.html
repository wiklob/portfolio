Code

Public repos on github.com/wiklob. I've coded almost daily for a year, but only fixed the email attached to my commits this May, hence the crater in the graph before it.

linear-mcp-lean self-hosted MCP proxy

Sits between the coding machine and Linear's MCP server and strips every response down to the fields agents actually read. About 75% fewer bytes per call, so 75% fewer tokens, and less waiting.

v-coding-setup my coding pipeline

The setup I work in, built on Linear + Claude Code. It breaks ideas into projects, projects into tickets, and then drives them to done with end-to-end /go runs.

claude-model-router model switching

Manages which models the Claude Code harness talks to. Makes CLIProxyAPI usable from inside the harness: switch models mid-session, pick custom ones straight from the native /model list.
