Wiktor Łoboda

I build things end to end: concept, code, design, and the unglamorous parts in between. Right now nearly all of that goes into reprint.

Now

reprint.so personal newspaper

Your personal newspaper: it aggregates your newsletters, news, Substacks and tweets. Read it as a web app, or let the layout engine set it as an actual newspaper. Three angles at once: a pretty reader, physical distribution, and a news aggregation tool. Making newspapers cool again.

Code

Public repos on github.com/wiklob. Coding daily for a year now.

wiklob.dev coding telemetry

Telemetry from some of my coding sessions. The tools producing it are built in-house, and they exist to auto-improve the coding setup itself.

linear-mcp-lean self-hosted MCP proxy

Sits between the coding machine and Linear's MCP server and strips every response down to fields requested by the caller. About 75% fewer bytes per call, so 75% fewer tokens, and less waiting.

v-coding-setup my coding pipeline

The setup I work in, built on Linear + Claude Code. It breaks ideas into projects, projects into tickets, and then drives them to done with end-to-end /go runs. Telemetry accessible at wiklob.dev.

claude-model-router model switching

Manages which models the Claude Code harness talks to. Makes CLIProxyAPI usable from inside the harness: switch models mid-session, pick custom ones straight from the native /model list. Do not use it: I got banned on ChatGPT for it, even though their chief Codexer recommended it.
